01 // Filosofía de Diseño

Ingeniería eficiente orientada a la contención de costes

Construir una infraestructura cloud robusta no consiste en acumular servicios gestionados caros en AWS o Azure. Mi metodología optimiza cada capa para exprimir al máximo servidores VPS o nubes híbridas, logrando disponibilidad del 99.9% con una fracción del coste mensual:

Backend Modular en NestJS

Estructura por dominios de negocio con validación estricta DTO (Zero-Trust), control de acceso por roles (RBAC) y soporte de WebSockets para tiempo real.

Frontend Angular SSR & Signals

Server-Side Rendering para un posicionamiento SEO perfecto en Google y gestión de estado reactivo fino con Signals sin penalizaciones de rendimiento.

PostgreSQL & Prisma Multi-Schema

Modelado relacional ACID con schemas modulares (`prismaSchemaFolder`), índices de consulta compuestos y políticas de menor privilegio (Least Privilege).

Pipelines CI/CD Zero-Downtime

Compilación desacoplada en la nube mediante GitHub Actions y despliegue idempotente con rsync y recarga en caliente supervisada por PM2.
