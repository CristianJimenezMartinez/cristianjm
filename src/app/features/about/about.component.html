El ingeniero detrás del código

Soy Cristian Jiménez Martínez (CristianJM), Full Stack Developer, especialista en Ciberseguridad DevSecOps y Software Architect. Arquitecto y Desarrollador de Bentian ERP Bridge: Middleware y conector local-first en tiempo real para Factusol ERP y tiendas online (WooCommerce y PrestaShop).

Diseño y construyo infraestructura de software empresarial de alto rendimiento combinando Node.js / TypeScript, servicios en Go y utilidades de sistema en C#. Especialista en acceso a datos de bajo nivel mediante controladores OLEDB sobre bases de datos Access (.accdb) de Factusol en red LAN y entornos NAS, garantizando concurrencia total sin bloquear puestos de facturación en la oficina.

Integro catálogos masivos, stock disponible en tiempo real y pedidos web con la WooCommerce REST API y plataformas PrestaShop mediante arquitecturas Local-First con tolerancia a caídas de red de hasta 30 días, además de gobernar servidores empresariales con despliegues automatizados desde GitHub y parcheo activo de seguridad.
